# FINDER SERVER

## OVERVIEW
THE FINDER SERVER IS A MODULAR PYTHON SERVICE DESIGNED TO EXTRACT EMPLOYEE AND STAFF DATA FROM LINKEDIN IN A RESILIENT AND FAULT-TOLERANT MANNER. IT REPLICATES CORE LINKEDIN SEARCH FUNCTIONALITY BY DIRECTLY INTERACTING WITH INTERNAL VOYAGER APIS.

## CORE MODULES

### AUTHENTICATION
MANAGES SESSION PERSISTENCE AND REDUNDANT LOGIN STRATEGIES.
- COOKIE AUTHENTICATION: USES LI_AT AND JSESSIONID FOR INSTANT ACCESS.
- PROGRAMMATIC LOGIN: MOBILE API-BASED BACKFALL FOR FRESH AUTHENTICATION.
- SESSION REUSE: PERSISTS COOKIES TO SESSION_TEST.PKL TO AVOID RATE LIMITS AND BANS.

### SCRAPER CLIENT
RESILLIENT HTTP WRAPPER WITH BUILT-IN REDUNDANCY.
- EXPONENTIAL BACKOFF: AUTOMATICALLY WAITS AND RETRIES ON 429 RATE LIMIT ERRORS.
- FAULT TOLERANCE: HANDLES TEMPORARY NETWORK FAILURES AND JSON PARSE ERRORS.

### PEOPLE FINDER ENGINE
ORCHESTRATES THE SEARCH PROCESS.
- COMPANY RESOLUTION: CONVERTS COMPANY NAMES OR SLUGS TO NUMERIC LINKEDIN IDS.
- GEO RESOLUTION: CONVERTS LOCATION STRINGS INTO LINKEDIN GEO URNS.
- PAGINATED SEARCH: FETCHES STAFF DATA IN BULK WITH MEMORY-EFFICIENT GENERATORS.

## USAGE (API SERVER)
1. CONFIGURE LINKEDIN_USERNAME AND LINKEDIN_PASSWORD IN THE .ENV FILE.
2. START THE FLASK SERVER:
   PYTHON3 APP.PY

3. THE SERVER WILL RUN ON PORT 5001 BY DEFAULT.

## API ENDPOINTS

### GET /FIND-PEOPLE
EXTRACTS STAFF DATA BASED ON COMPANY NAME.
- PARAMETER: COMPANY (REQUIRED) - THE COMPANY NAME OR LINKEDIN SLUG.
- PARAMETER: SEARCH_TERM (OPTIONAL) - FILTER BY JOB TITLE OR KEYWORD.
- PARAMETER: LOCATION (OPTIONAL) - FILTER BY GEOGRAPHIC REGION.
- PARAMETER: MAX_RESULTS (OPTIONAL) - LIMIT THE NUMBER OF RESULTS (DEFAULT 10).

### EXAMPLE REQUEST:
CURL "HTTP://127.0.0.1:5001/FIND-PEOPLE?COMPANY=WIREONE%20LABS&MAX_RESULTS=5"

### GET /HEALTH
CHECKS IF THE SERVER IS RUNNING AND THE LINKEDIN SESSION IS VALID.
CURL "HTTP://127.0.0.1:5001/HEALTH"
